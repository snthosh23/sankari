# Sankari Love Website ❤️

## How to use
1. Extract this ZIP.
2. Open `index.html` in Chrome/Edge.
3. Replace `assets/couple.jpg` with your own photo (keep the same filename).
4. Edit the text in `index.html` if you want to add your real memories.
5. For hosting, upload the folder to Netlify/Vercel/GitHub Pages.
6. Generate a QR code using your final website URL and print it on your letter or chocolate box.

## Files
- index.html — complete website content
- style.css — design, responsive layout and animations
- script.js — interactions
- assets/couple.jpg — replace with your own photo

## Suggested gift flow
Letter → QR scan → website → poem → letter → chocolate notes → real gift reveal.
